## 实际遇到的环境情况

- 首次 Maven 下载在受限执行环境中报 `Permission denied: getsockopt`；通过授权网络执行后依赖下载成功。
- 一次 zstd-jni 下载报 `Premature end of Content-Length delimited message body`，重试后成功。没有更换不明来源的仓库。
- Windows 锁定正在运行的 JAR 时，`clean` 不能删除该文件。关闭测试客户端后重试成功。
- JavaFX classpath 模式产生 `Unsupported JavaFX configuration: classes were loaded from unnamed module` 警告。实际编译、运行和窗口测试通过；此警告保留在日志中。
- 独立服务器绑定局域网地址时出现 Windows 防火墙授权窗口，代理未操作该安全弹窗，也未修改防火墙设置。本机回环测试无需开启局域网入站权限；跨电脑连接需要用户在可信网络自行授权。
